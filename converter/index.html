How to Use

  1. Get a .mcstructure file (from Structure Block or download)
  2. Upload it here using the box above
  3. Copy or download the converted JSON
  4. Paste into blueprint_bp/scripts/blueprints.js
  5. Load in-game with /scriptevent blueprint:load name

Where to Find .mcstructure Files

  1. In Minecraft: /give @s structure_block
  2. Place the block, set to "Save" mode
  3. Define the area and save
  4. Find file in: com.mojang/structures/
